🚀 Quick Start

Lua scripts in GTPS Cloud are loaded automatically on server start. Create a .lua file and upload it through the File Manager in your dashboard.

📝 Basic Template

-- Basic GTPS Cloud script template
print("(Loaded) My Script")

registerLuaCommand({
    command = "hello",
    roleRequired = 0,
    description = "Greet a player"
})

onPlayerCommandCallback(function(world, player, fullCommand)
    local cmd = fullCommand:match("^(%S+)")
    if cmd ~= "hello" then return false end
    
    player:onConsoleMessage("Hello, world!")
    return true
end)

⚠️ Important Notes

🔒 Don't pass Player objects into timers Use getUserID() to store a reference.
💾 Save data inside onAutoSaveRequest Save all your Lua state here.
⚡ Avoid heavy computation in onTick These callbacks fire every 100ms.
